# 02 — Development chronology (2026-09-30 → 2026-11-12)

Subject: `storytold/photocraft`, `main` pinned at `74330157cb601573ae4523a95bb9132822fc3918` (2026-11-12).
All times are **UTC committer dates** unless marked (author dates and `-0400` founder times are converted).
Squash-merge commits carry the merge time as their date (E03 C4). Evidence IDs (`E05-004`) point to
`evidence/E0x-*.md`; the underlying sha/PR/URL is given beside each. Corrections in `01c-errata.md` override
the evidence files and are applied here. Labels: **VERIFIED** (observed in git or a cited page), **INFERRED**
(reasoned; chain given), **PROPOSED** (not used in this deliverable except where marked).

Reading guide. The goal is to show how the *development method* changed, not only what shipped. Section 1 is
the one-page overview (phases). Section 2 is the master timeline. Section 3 is the week-by-week metrics
strip. Section 4 pairs incidents with the process changes that followed them. Section 5 lists what the
chronology cannot see.

Terms used below (defined once):
- **AI attribution** — an explicit signal in a commit: a `Co-authored-by:` line naming an AI tool, an AI
  author identity (`Claude`, `Codex`), a `Claude-Session:`/`Copilot-Session:`/`Model-Effort:` trailer or a
  "Generated with Claude Code" line (E03 C7). A commit without one is **attribution unknown**, not "human".
- **Squash PR** — a PR landed as one first-parent commit `Title (#N)` committed by `GitHub`.
  **Merge-commit PR** — landed as `Merge pull request #N from owner/branch`, importing the whole branch.
- **Integration batch** — a branch that merges many PRs (with fix-ups and conflict resolutions) so they get
  one CI run and land together (E06-021/022).
- **House rules** — the 15 org-wide agent/contributor rules copied into `AGENTS.md` from
  `storytold/craft-contrib` on 11-06, hash-checked by CI (E02 §2.1).
- **panic_hunt** — an `#[ignore]`d integration test that fuzzes every registered command with hostile
  parameters (E01-027, E05-071).
- **Scorecard** — `docs/scorecard.md`, generated by `cargo xtask scorecard` from TOML goal rows and checked
  fresh by CI (E01-018).
- **Red main** — `main` failing CI; **merge skew** — two PRs each green alone that break `main` together
  (E07-003).
- **craftrules** — a private shared-standards repo of the "Craft" app family, cited from 10-01, retired by
  10-31 (E01-023, E02 §1 rev 35).

## 1. Overview: six phases of method

**Finding.** The method moved through six phases in 44 days: a solo founder pushing agent-produced
checkpoints (P1); a switch to PRs, rules-from-incidents and a contributor flood (P2); a squash-merge flood
run by maintainers with agent sweeps and CI scaled for throughput (P3); maintainer-run integration batches
landing fork PRs as merge commits, with bot review added (P4); consolidation onto org-shared CI and
standards (P5); and a governance/release-branch phase with hash-checked house rules, a manual merge queue
and releases cut off `main` (P6). Each boundary below is **INFERRED** (my interpretation); the event that
fixes it is VERIFIED and cited.

### 1.2 Phase sketches

**P1 — Solo founder genesis (09-30 → 10-03).** One author, 69 direct pushes, no PRs. Day 0 is an empty
`init repo` (`386b0566d3`) then a 241-file, +42,241-line "one-shot" (`16941f7198`) that already contains
`AGENTS.md` with parallel-agent rules, CI, and a gitignored private `plan/` and `log/` (E01-002/003/005).
First AI trailer 32 h later (`1f1ddb2a47`, 10-01 17:25); commits are multi-agent *checkpoints* ("+ in-progress
work of other agents", `aa87012aab`). Planning is a generated parity checklist (`536a7346fb`) and an
agent-hour estimate citing "8 parallel agents" (`0c2d4bfd1a`). Release pipeline on day 2 (`d98bee4c94`).
*Start-of-phase process:* AGENTS.md as day-0 artefact; CI with fmt/clippy/layers/wasm.
*Boundary to P2 fixed by:* the first non-founder commit and first PR squash on 10-04 (`b6a95b6c8d`,
`b7cac05f69`).

**P2 — Opening: PR flow, contributor influx, rules from incidents (10-04 → 10-07).** HN launch traffic
(issue #1, 10-01: "found this project from your comment on HN", via WebFetch, E01-025) turns into 64
authors and 391 squash PRs in four days. User crash reports produce rule 9 "Never panic on input" within a
day and a 12-PR "never crash" sweep (E07-009). The parity metric is publicly demoted ("We are far from real
Photoshop parity", `20783fdc70`). Scorecard and pinned corpora arrive (`0f955e6c82`, `968baf639e`). The
phase ends with the first visible red-main cluster and the discovery that main CI runs were being cancelled
(`07174271d5`). *Boundary to P3 fixed by:* 10-08 — first `claude/*` branches, first `Claude-Session:`
trailer, first `Claude` author identity, first CI-only integration trains (E01-029, E06-021).

**P3 — Squash flood and maintainer agent sweeps (10-08 → 10-17).** Peak throughput: 1,838 PRs in 10 days,
99 % squash-merged (`data/E03_pr_weekly.csv`). A second maintainer (BFlat/bflatastic) runs Claude sessions
under the `Claude` identity over open issues (`claude/fix-<issue>-*`, 17 branches) and community PRs
(`claude/integ-batch-1..11`, CI only), 10-08/09 (E06-021/024). Planning is rewritten in "Opus 5.5 agent
wall-clock hours" with "10–20 concurrent agents" (`939c8f2c70`, 10-10). CI is re-engineered for cost and
speed: macOS off PRs, nextest, Windows split, shared `craft-common-actions` (E05-003). Mechanical checks
replace prose rules (`xtask panel-commands`, `4165c57f92`; panic_hunt in CI, `45afd2e9d7`).
*Boundary to P4 fixed by:* 10-18 — first maintainer integration-batch merge (`5c89f16b60`, aiongg
`integration-2`, #7432), CodeRabbit/SonarCloud badges (`18f8d33577`), Dependabot (`9185b64b94`).

**P4 — Integration batches and bot review (10-18 → 10-28).** Landing switches from squash to merge commits:
10-21 is the first day with more merge-commit than squash landings (1 vs 11, `data/E03_pr_daily.csv`).
aiongg (`integration-2..10`) then David Mann's fork (`integration-batch-7..9`, 44/37/21 PRs per batch)
stage community PRs, revert failing ones inside the batch and land them in one merge commit (E06-022,
E07-002). CodeRabbit reviews every sampled PR; SonarCloud scans start 10-21 and seed lint gates
(`604da9d06b`, cognitive complexity denied, 10-27). Red-main commits drop to 0 in W43–W45 (E07-005).
Distinct authors fall from 277 (W42) to 77 (W44). *Boundary to P5 fixed by:* 10-29/30 — FredApps'
108-PR fork-integration protocol (`46c1347951`) and the AGENTS.md "CI workflows" rule (`0379569d00`).

**P5 — Consolidation onto shared org infrastructure (10-29 → 11-04).** The lowest-throughput week (W44: 70
PRs). Process becomes documentation and standardisation: an approval-receipt integration protocol
("A zero-match run is BLOCKED, never PASSED", E05-022), "Don't add or change CI in a feature or fix PR"
(E05-012), craftrules references removed (`6d737c219e`), `fail-fast = false` (`8c8c4b95f5`). Batches
10–16 continue, now "epic PRs". *Boundary to P6 fixed by:* v0.20.2 (`7c12f64715`, 11-05 00:49), the
first tag that is not an ancestor of `main` (E03-015).

**P6 — Governance and release-branch era (11-05 → 11-12).** Releases are cut on `origin/release` by Dylan
M. Taylor and FredApps instead of the founder (E05-065). The 15 house rules arrive hash-checked from
`craft-contrib` (`7d8648dfcb`, 11-06), including "**No agent attribution.**" and "`main` changes through a
pull request". The last integration batch lands the same day (`6b0f7762e1`, batch 20); thereafter PRs land
individually as merge commits through a **manual** "(merge queue)" (`fda05f7b02`, 11-08; 7 on main per
01c-errata #2). Structured `Model-Effort:` role trailers appear (`b29fdc5a29`, 11-08). The phase ends with
an 11-11 merge wave (180 PRs landed on 11-11, 146 of them as merge commits, `data/E03_pr_daily.csv`), an 11-commit "Fix main"
cluster and a release-day failure answered by a nightly release dry run (`f1b5e7d727`).

computed over very few direct/squash commits (36, 93, 69) and is not a trend signal.

## Appendix A — `phases.py` (verbatim, stdlib only)

```python
# Per-phase metrics for deliverable 02. Usage: python3 -I phases.py <upstream> <study-repo>
import sys, subprocess, re, csv, datetime as dt, collections
U, S = sys.argv[1], sys.argv[2]
PIN = "74330157cb601573ae4523a95bb9132822fc3918"
PH = [("P1","2026-09-30","2026-10-03"),("P2","2026-10-04","2026-10-07"),("P3","2026-10-08","2026-10-17"),
      ("P4","2026-10-18","2026-10-28"),("P5","2026-10-29","2026-11-04"),("P6","2026-11-05","2026-11-12")]
ph = lambda d: next(p for p,a,b in PH if a <= d <= b)
CO = re.compile(r"^[\s*>-]*co-authored-by:\s*(.*?)\s*(<([^>]*)>)?\s*$", re.I|re.M)
AIN = re.compile(r"^(Claude\b.*|GPT-?\d.*|(OpenAI )?Codex.*|Cursor( Agent)?|Copilot|Codebuff|Devin|DeepSeek.*|Qwen.*|Gemini.*|Grok.*)$", re.I)
AIE = re.compile(r"(@anthropic\.com|@openai\.com|@cursor\.com|@codebuff\.com|@qwen\.ai|@deepseek\.com|\+copilot@users\.noreply\.github\.com)", re.I)
SESS = re.compile(r"^\s*(Claude-Session|Copilot-Session|Model-Effort):", re.I|re.M)
GEN = re.compile(r"generated with \[?(Claude Code|Codebuff|Codex)", re.I)
alias = {}
for r in csv.DictReader(open(S+"/data/E03_alias_map.csv")):
    for a in r["merged_aliases"].split("; "):
        if a: alias[a] = r["canonical_name"]
out = subprocess.run(["git","-C",U,"log",PIN,"--format=%x1e%P%x1f%an%x1f%ae%x1f%cI%x1f%B"],capture_output=True,text=True).stdout
M = collections.defaultdict(lambda: dict(all=0,nm=0,ai=0,auth=set()))
for rec in out.split("\x1e")[1:]:
    par,an,ae,ci,body = rec.split("\x1f",4)
    d = dt.datetime.fromisoformat(ci).astimezone(dt.timezone.utc).date().isoformat()
    m = M[ph(d)]; m["all"] += 1; m["auth"].add(alias.get(an,an))
    if len(par.split()) > 1: continue
    m["nm"] += 1
    ai = any(AIN.match(x.group(1).strip()) or AIE.search(x.group(3) or "") for x in CO.finditer(body)) \
         or ae.lower().endswith(("@anthropic.com","@openai.com")) or re.match(r"^(Claude|Claude Opus.*|Codex)$",an) \
         or SESS.search(body) or GEN.search(body)
    m["ai"] += bool(ai)
pr = collections.Counter(); sq = collections.Counter()
for r in csv.DictReader(open(S+"/data/E03_pr_daily.csv")):
    pr[ph(r["day_utc"])] += int(r["prs_landed"]); sq[ph(r["day_utc"])] += int(r["squash_prs_landed"])
rel = collections.defaultdict(list)
for r in csv.DictReader(open(S+"/data/E03_releases.csv")):
    rel[ph(r["commit_date_utc"][:10])].append(r["tag"])
print("phase|days|commits|non-merge|authors|AI-attr non-merge|PRs landed (squash)|tags")
for p,a,b in PH:
    m = M[p]; n = (dt.date.fromisoformat(b)-dt.date.fromisoformat(a)).days+1
    print(f"{p}|{a}..{b} ({n}d)|{m['all']}|{m['nm']}|{len(m['auth'])}|{m['ai']} ({100*m['ai']/m['nm']:.1f}%)|{pr[p]} ({sq[p]})|{len(rel[p])}: {' '.join(rel[p])}")
print("TOTAL", sum(m['all'] for m in M.values()), sum(m['nm'] for m in M.values()), sum(m['ai'] for m in M.values()))
```
